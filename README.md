#### 2026-07-06 / 07-07 / 07-08
- **학습 내용**: 객체지향 프로그래밍 I - 클래스와 객체, 변수와 메서드 (`_ch06`)
- **요약**:
    - **소스파일 작성 규칙**: `public class` 명과 소스파일명의 관계 및 하나의 소스파일 내 클래스 정의 제한 규칙 실습.
    - **클래스와 객체**: 객체의 정의와 클래스 구조, `new` 연산자를 통한 인스턴스 생성 및 멤버 변수/메서드 사용법 이해.
    - **변수의 종류**: 인스턴스 변수와 클래스 변수(`static`)의 선언 위치 및 공유 메커니즘 차이 분석.
    - **메서드 정의와 호출**: 매개변수 선언, 반환 타입 및 값 반환 흐름을 학습하고, `Math.round()`를 적용한 메서드 구현 실습.
    - **메서드 오버로딩(Method Overloading)**: 동일한 이름의 메서드를 매개변수의 개수나 타입을 달리하여 여러 개 정의하는 방법과 컴파일러의 메서드 선택 과정을 이해.
    - **생성자(Constructor)**: 객체 생성 시 자동으로 호출되는 생성자의 역할과 기본 생성자, 매개변수가 있는 생성자를 이용한 객체 초기화 방법을 학습.
    - **`this`와 `this()`**: 현재 객체를 가리키는 참조변수 `this`와 같은 클래스의 다른 생성자를 호출하는 `this()`의 차이 및 활용 방법을 실습.
    - **변수 초기화**: 기본값 초기화, 명시적 초기화, 초기화 블록, 생성자를 이용한 초기화 방법과 클래스 변수 및 인스턴스 변수의 초기화 순서를 학습.
    - **반환값(`return`)**: 메서드의 종료와 반환값 전달 방식, `void` 메서드와 반환형이 있는 메서드의 차이를 학습.
    - **호출스택(Call Stack)**: 메서드 호출과 종료 과정에서 스택(LIFO) 구조로 메모리가 할당(Push)되고 해제(Pop)되는 실행 흐름 이해.
    - **기본형과 참조형 매개변수**: 값 복사와 참조 복사의 차이를 비교하고, 메서드 호출 시 원본 데이터에 미치는 영향을 실습.
    - **인스턴스 메서드와 `static` 메서드**: 두 메서드의 호출 방식과 사용 목적을 비교하고, `static` 메서드에서 인스턴스 멤버를 직접 사용할 수 없는 이유를 이해.

#### 2026-07-09 / 07-10
- **학습 내용**: 객체지향 프로그래밍 II - 상속, 포함, 오버라이딩, 제어자, 캡슐화 (`_ch07`)
- **요약**:
    - **상속 (Inheritance)**: `extends` 키워드를 이용해 기존 클래스를 재사용하여 새로운 클래스를 정의하는 방법 학습. 자식 클래스는 부모 클래스의 모든 멤버를 물려받음.
    - **클래스 간 관계 (is-a / has-a)**: 상속(is-a)과 포함(has-a) 관계의 차이를 이해하고 적합한 설계 방식을 선택하는 기준 학습.
    - **메서드 오버라이딩 (Overriding)**: 부모 클래스의 메서드를 자식 클래스에서 재정의하는 방법과, 오버라이딩(재정의)과 오버로딩(중복 정의)의 차이를 이해.
    - **패키지 (Package)**: 서로 관련된 클래스들을 묶는 물리적인 폴더 구조 및 Fully Qualified Name(FQN) 개념 학습.
    - **접근 제어자 (Access Modifier)**: `private`, `default`, `protected`, `public`의 특징과 허용 범위를 파악하여 멤버에 대한 접근을 적절히 차단하는 방법 이해.
    - **캡슐화 (Encapsulation)**: 외부 유입 값 제한을 위한 `private` 멤버 변수 선언 및 `Getter / Setter`를 이용한 데이터 필터링/보호 방법 실습.

#### 2026-07-13
- **학습 내용**: 객체지향 프로그래밍 II - 다형성과 제어자, 추상 클래스 (`_ch07`)
- **요약**:
    - **제어자 (Modifier)**: 클래스, 변수, 메서드에 붙는 `static`, `final`, `abstract` 제어자의 역할과 쓰임새를 학습하고 이를 올바르게 선언하는 실습 진행.
    - **다형성 (Polymorphism)**: 조상 타입 참조변수로 자손 객체를 가리키는 원리와 자손 간 참조변수의 업캐스팅/다운캐스팅 형변환 규칙 실습.
    - **매개변수의 다형성**: 메서드 매개변수에 부모 클래스 타입을 대입하여 여러 종류의 자식 객체들을 공통 메서드로 간결하게 처리하는 유연성 확보.
    - **다형성 객체 배열**: 조상 타입의 배열 구조를 구축해 여러 자식 클래스의 인스턴스를 하나의 배열(장바구니) 내에서 통합 관리하는 방법 학습.
    - **추상 클래스와 추상 메서드**: `abstract` 키워드를 활용해 미완성 설계도(추상 클래스)를 구성하고, 자식 클래스에서 선언된 모든 추상 메서드를 구체화(오버라이딩)하도록 유도하는 설계 기법 실습.

- **학습 내용**: 객체지향 프로그래밍 II - 인터페이스와 느슨한 결합 (`_ch07`)
- **요약**:
    - **인터페이스 (Interface)**: 상수와 추상 메서드로만 구성된 추상화 등급이 높은 미완성 설계도 정의 및 다중 상속 구현 방법 학습.

    - **느슨한 결합 (Loose Coupling)**: 선언과 구현을 분리하여 구현체 변경 시에도 호출부 코드 변경을 최소화하는 유연한 설계 원리 학습.
